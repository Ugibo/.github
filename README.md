# Ugibo/.github

The organisation profile and the default community files for every Ugibo repository.

| Where | What |
| --- | --- |
| `profile/README.md` | The page shown at [github.com/Ugibo](https://github.com/Ugibo). |
| `profile/assets/` | Its banner and Boo, made by `brand/assets/make-readme-art.py`. Do not edit by hand. |
| `SECURITY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md` | Used by any repository that has none of its own. |
| `ISSUE_TEMPLATE/`, `pull_request_template.md` | The default issue forms and pull request checklist. |
