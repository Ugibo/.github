# Contributing

Thanks for wanting to help. Most Ugibo repositories are private; this applies to the public
ones, such as [`Ugibo/mcp`](https://github.com/Ugibo/mcp).

1. **Open an issue first** for anything bigger than a typo, so we can agree on it before you
   spend time on code.
2. **Keep a pull request to one change.** Say what it fixes and how you checked it.
3. **Follow the code around you**: its naming, its structure, its tests.
4. **Never commit secrets.** No `.env` files, keys or tokens.

Security problems go by email, not as issues: see [SECURITY.md](SECURITY.md).
