# Code of conduct

Be kind, be direct, and assume good intent. Talk about the work, not the person.

Harassment, insults and personal attacks are not welcome in any Ugibo space: issues, pull
requests, discussions or email. We will remove content that breaks this and may block
whoever posted it.

To report something, email [team@ugibo.com](mailto:team@ugibo.com). We will keep it
private.
