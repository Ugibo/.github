# Security policy

If you find a security problem in anything Ugibo makes, please tell us privately before
telling anyone else.

**Email [team@ugibo.com](mailto:team@ugibo.com)** with "Security" in the subject. Say what
you found, where, and how to reproduce it. Please do not open a public issue for it.

We will reply within three working days, keep you told while we fix it, and credit you when
it is fixed if you would like that.

Please do not access or change data that is not yours, and do not run tests that would slow
or break the service for others.
